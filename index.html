My project is called the Smart Rain Detection and Alert System. It is an Arduino-based system designed to detect the intensity of rainfall using a rain sensor. The sensor continuously measures the amount of water or moisture on its surface and sends an analog value to the Arduino. The Arduino then analyzes this value and determines whether there is no rain, light rain, or heavy rain. Depending on the detected level, different LEDs are activated. The green LED indicates no rain, the yellow LED indicates light rain, and the red LED indicates heavy rain.

The system operates in a simple sequence: Rain falls on the sensor, which is connected to the Arduino UNO. The Arduino checks the rain level and classifies it as no rain, light rain, or heavy rain. For each condition, the system responds with the corresponding LED. If the rain is heavy, the buzzer is also turned on for an audible alert. Finally, the LCD display shows the rain status so the user can monitor the condition clearly and quickly.
